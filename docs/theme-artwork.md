## UI design

The deep-sea palette uses a navy shell with cyan highlights; the pearl-dragon palette uses an ivory/lavender shell and mint highlights. Artwork lives in a bounded header banner, never behind quota values. Red/amber warnings retain their semantic colors. Focus mode removes the banner while preserving all data and controls. There is no idle animation; hover movement is disabled when reduced motion is preferred.
