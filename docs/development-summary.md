# Development Summary

## 2026-11-03 按订阅选择额度窗口

- 功能：Plus 展示 5 小时窗口，已知 Pro 系列及组织订阅展示周窗口。卡片与 Web 仪表盘一致；每次刷新重新判断，账号切换不沿用旧的窗口选择。
- 主要入口：`lib/codex.js` 的 `decodeUsageResponse` 将上游数据归一化并选择窗口；`loadStatus` 将未识别订阅或窗口缺失警告放入 `errors`；`makeNudge` 为 5 小时窗口提供独立建议。`app/page.jsx` 和 `app/widget/page.jsx` 显示 `5H` 或 `W`。
- 数据边界：只信任 usage 响应的订阅类型和窗口时长，不从窗口位置猜测订阅、不读取额外凭据。只有 18000 秒和 604800 秒分别视为 5H 与周窗口。缺失或未知订阅不自动视为高阶订阅；缺失目标窗口不回退到另一窗口；缺失使用率仍为未知。
- 技术决策：显式维护支持的高阶计划标识，避免把 Free、Go 或未来未知计划误分类。Plus 建议不套用周额度刷新时间或储备重置建议，因为未验证其兑换适用性。保留现有只读重置展示和周额度建议。
- 相关接口字段及来源见 [API Notes](api-notes.md)。未改动认证、兑换、发布流程或依赖版本。
- 验证：`npm test` 的 20 项测试通过，覆盖大小写、camelCase、窗口互换、未知订阅、缺失字段、计划切换及 Plus 建议。`npm run build` 通过（含 standalone 准备），本地服务成功启动，但当前环境中的 HTTP 冒烟请求未连通（HTTP 000）。Playwright 页面交互验证未能执行：当前运行环境禁止 Chromium 创建本地 socket，即使请求提升后仍失败。因此实际自动刷新、账号切换交互和 Windows 原生卡片及真实账号接口未实测。

## 2026-11-03 美国太平洋参考时钟

- 新增 `lib/clock.js`：固定 en-US 12 小时制，以 IANA America/Los_Angeles 转换电脑系统时间。显示日期、秒、AM/PM、PST/PDT 和 UTC 偏移，不用固定 UTC−8，也不依赖用户本地时区。
- 新增共享客户端组件 `app/components/AnnouncementClock.jsx`：每秒独立刷新，不触发额度 API 请求；从隐藏/休眠恢复或窗口聚焦时重新读取当前时间。卸载清理计时器和事件。首次服务端/客户端渲染均为占位，避免 hydration 时间差。
- `app/page.jsx` 与 `app/widget/page.jsx` 接入同一时钟。新增墨绿玻璃面板、大号等宽数字和清晰时区标识。屏幕阅读器有完整时间标签，不每秒主动播报。小窗口内部滚动保留底部内容可达性，拖动区域限定为顶部标题栏，滚动区域及设置/刷新按钮不参与窗口拖动。
- 数据边界：只使用本机系统时钟和 Intl，无新依赖、外部请求、凭据或持久化。此时钟仅作公告参考，不解析 X，不推断下一次额度重置时间。API 文档无需修改。
- 验证：26 项单元测试通过，涵盖春秋夏令时切换、午夜/中午、跨日期、不同系统时区和无效输入；生产构建、语法及 diff 检查通过。云浏览器连接本地预览地址被拒绝，视觉与 Windows 原生拖动/滚动尚未实测。临时预览进程已关闭。

## 2026-11-04 双角色主题与专注模式

- `ThemeProvider` 在首页与桌面卡片共享外观状态；默认保留经典主题。选择深海或白龙后仅改变配色与角色装饰，额度、时钟、重置和设置功能保持独立。
- `lib/themes.js` 与 `desktop/appearance.cjs` 提供三个主题的白名单和严格布尔专注标记。浏览器存储损坏时回退经典；服务端/首次客户端渲染一致，防止 hydration 不匹配。
- Electron 通过限定的 getAppearance/setAppearance IPC 将外观写入原有 settings.json，避免随机本地端口导致设置丢失。慢速 IPC 在 1.5 秒后允许交互，但后续结果只在用户没有新选择时应用。保存失败在界面提示，不阻断监控。
- 两个本地透明 PNG 为文字提示生成的原创角色，未包含参考网站的受限插画；来源与设计说明见 theme-artwork.md。无新依赖、外部图片请求或额度 API 请求。
- 样式支持专注模式、键盘焦点、选中状态、强制颜色及减少动态效果。桌面紧凑横幅与可滚动内容区保留核心信息可达性。
- 验证：31 项单元测试覆盖原有额度/时钟行为及外观验证、损坏存储、序列化和本地图片检查；生产构建、JS 语法和 diff 检查通过。独立代码复核未发现阻断问题。云浏览器无法连接执行环境预览端口，且 file 协议被其安全策略禁止，因此未完成实际浏览器布局、交互与 Windows 原生重启持久化测试；没有声称这些已验收。临时服务器已关闭。
